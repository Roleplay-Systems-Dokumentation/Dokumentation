## So startest du

Der Roleplay Systems Bot ist kostenlos und mit wenigen Klicks auf deinem Server eingerichtet.

1. **Öffne das Dashboard** Melde dich mit Discord an und wähle deinen Server aus.
2. **Lade den Bot ein** Füge den Bot mit Klick auf den entsprechenden Server hinzu.
3. **Module einrichten** Nutze die Slash-Befehle um die einzelnen Module zu aktivieren.
