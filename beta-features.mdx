</Warning>

## Was ist der BETA-Bot?

Um dir Vorab-Zugriff auf neue Funktionen zu geben, ohne die Stabilität deines Haupt-Servers zu gefährden, testen wir neue Features in einer separaten Bot-Instanz.

- **Haupt-Bot:** Übernimmt alle stabilen, fertigen Module im Live-Betrieb.
- **BETA-Bot:** Führt ausschließlich Module aus, die sich aktuell in der Entwicklungs- oder Testphase befinde.

---

## BETA-Bot einladen

Damit du Module mit dem **[BETA]**-Tag auf deinem Server nutzen kannst, musst du den BETA-Bot zusätzlich zu deinem Server hinzufügen und in den Server-Einstellungen "Beta-Features" aktiviert haben:

## Wichtige Hinweise zur Nutzung

<AccordionGroup>
  <Accordion title="Muss ich den Haupt-Bot entfernen?">
    **Nein.** Beide Bots können und sollten nebeneinander auf deinem Server laufen. Der Haupt-Bot reagiert weiterhin auf die Standard-Module, während der BETA-Bot nur für die [BETA]-Module zuständig ist.
  </Accordion>

  <Accordion title="Kann es bei BETA-Modulen zu Fehlern kommen?">
    Ja, BETA-Funktionen befinden sich in aktiver Entwicklung. Es kann gelegentlich zu Unterbrechungen oder unerwartetem Verhalten kommen.
  </Accordion>

  <Accordion title="Wie gebe ich Feedback zu BETA-Features?">
    Wenn du Fehler findest oder Verbesserungsvorschläge hast, erstelle bitte ein Ticket auf unserem [Discord Support-Server](/discord).
  </Accordion>
</AccordionGroup>
