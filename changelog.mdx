<Update label="01.11.2026" description="v2.7.0">
  ## Version 2.7.0

  - **Schicht-System:** TeamZeit + Setup-Wizard hinzugefügt.
  - **VIP-System:** Das VIP-System wurde erweitert.
  - **Personensystem:** Setup erweitert und Liste in einen Kanal senden bei Membern ohne Eintrag.
  - **Zentrales Setup:** Grundlegendes Setup (`/setup` und automatisch bei Bot-Beitritt) für Serversprache, Roblox (Ja/Nein) und Broadcastkanal, welche global für alle Module gelten.
  - **Fahrzeugsystem:** Custom-Fahrzeuge sind nun bis zu 3 für alle verfügbar, darüber hinaus als VIP-Funktion inklusive neuem Setup.
</Update>

<Update label="26.10.2026" description="v2.6.0">
  ## Version 2.6.0

  ### Personensystem

  - **Roblox-Verknüpfungen:** Unterstützung für Roblox-Gruppenverknüpfung und Roblox-Nutzernamen.

  - **Neues Menü:** Überarbeitete Benutzeroberfläche.

  - **Design & Usability:** Neues Design, einfacher, benutzerfreundlicher und höher anpassbar.
  - **Transkripte:** Transkripte funktionieren wieder einwandfrei.

  - **Multi-Server:** Server 1 / Server 2 (VIP) steuerbar.
  - **V2 Components:** Aktualisiert auf V2 Components.
  - **DM-Zustellung:** Fehler behoben – Zustellung erfolgt nun ohne Rate-Limits.
  - **Serverstatus Integration:** Server 1 dient als Quelle für das "Serverstatus"-Modul.

  ### Serverstatus

  - **Quelle:** Server 1 des RP-Moduls ist nun die zentrale Quelle.
</Update>
