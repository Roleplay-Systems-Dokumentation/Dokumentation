Das Team-Dashboard ist ein zentraler Ort für dein Team. 

# Was ist das Team-Dashboard?

Im Team-Dashboard kan dein Team sich abmelden, chaten, Daten abrufen, verwarnen, Nutzer ID's bekomen und vieles mehr

# Wie kome ich zum Team-Dashboard?

mit diesem Link [https://teams.nrw-roleplay.de/](https://teams.nrw-roleplay.de/), der Eigentümer des Servers mus das Team-Dashboard freigeben damit das Team auf das Team-Dashboard zugreifen kan
