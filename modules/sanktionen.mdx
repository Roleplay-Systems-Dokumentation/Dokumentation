Das Case-System dient dazu, In-Game-Bestrafungen über ein Menü einzutragen und zu protokollieren. Du kannst dafür separate Kanäle und eine Verwaltungsrolle festlegen. Entbannungsanträge können in Verbindung mit diesem System erstellt werden.

## Einrichtung

Führe `/case-setup` aus und lege im Menü die folgenden Einstellungen fest:

| Einstellung | Beschreibung |
| --- | --- |
| Kanal für Cases | Kanal, in dem das Case-Menü erscheint. |
| Rolle für Case-Verwaltung | Nur Mitglieder mit dieser Rolle dürfen das Menü verwenden. |
| Statistik-Kanal | Optionaler Kanal für Statistiken und eine allgemeine Übersicht. |
| Beweis erforderlich | Lege fest, ob beim Erstellen eines Cases ein Nachweis, etwa ein Screenshot oder Clip, angehängt werden kann. |
| Kanal für Bestrafungs-Logs | Kanal für Protokolle zu Bestrafungen und Exporten. |
| Kanal für „Ban ausstehend“ | Kanal für Nachrichten zu Bans, die ausgeführt werden sollen, während ein Nutzer noch im Spiel ist. |

Über den Button **Kanäle automatisch erstellen** kannst du eine Kategorie mit den zugehörigen Kanälen erstellen lassen. Der Bot benötigt dafür die passenden Discord-Berechtigungen.

Im Setup kannst du außerdem **Ban ausstehend** aktivieren oder deaktivieren.

<Note>
  Richte das Modul über `/case-setup` in Discord ein. Im Dashboard kannst du eine vorhandene Konfiguration anpassen, aber kein Modul neu aktivieren.
</Note>

## Berechtigungen und Hinweise

- Vergib die Case-Verwaltungsrolle nur an zuständige Teammitglieder.
- Wenn du die automatische Kanalerstellung verwendest, prüfe die Bot-Berechtigungen zum Erstellen von Kategorien und Kanälen.
- Lege einen Statistik- und Log-Kanal nur fest, wenn diese Übersichten beziehungsweise Protokolle für dein Team benötigt werden.
