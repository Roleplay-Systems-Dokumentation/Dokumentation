Das Geburtstagssystem ermöglicht Mitgliedern, ein Geburtsdatum zu hinterlegen und eine Geburtstagsbenachrichtigung auszuwählen. Eine optionale Rolle kann am Geburtstag vergeben werden.

## Einrichtung

Führe `/birthday-setup` aus und konfiguriere:

- **Geburtstagskanal:** Kanal für das Geburtstagspanel und Benachrichtigungen.
- **Geburtstagsrolle (optional):** Temporäre Rolle, die an Mitglieder mit Geburtstag vergeben wird.

<Note>
  Richte das Modul über `/birthday-setup` in Discord ein. Im Dashboard kannst du eine vorhandene Konfiguration anpassen, aber kein Modul neu aktivieren.
</Note>

## Geburtstage verwalten

| Befehl | Zweck |
| --- | --- |
| `/birthday-set` | Hinterlegt Tag und Monat. Eine Geburtstagsbenachrichtigung kann optional ausgewählt werden. |
| `/birthday-edit` | Ändert ein bereits hinterlegtes Geburtsdatum oder die Benachrichtigung. |
| `/birthday-delete` | Löscht sämtliche gespeicherten Geburtstagsdaten. |
| `/birthday-greet-resend` | Sendet die Benachrichtigung für den aktuellen Geburtstag erneut in den Geburtstagskanal. |

Beim Hinterlegen eines Geburtstags erscheint eine Datenschutzabfrage. Das Geburtsdatum wird erst gespeichert, nachdem das Mitglied mit ✅ **Annehmen** zugestimmt hat.

## Hinweise

- Informiere Mitglieder darüber, dass sie die Speicherung ausdrücklich bestätigen müssen.
- Die Löschung über `/birthday-delete` entfernt alle Geburtstagsdaten des Mitglieds.
- Wähle eine temporäre Rolle, die für den Geburtstagszeitraum gedacht ist.
