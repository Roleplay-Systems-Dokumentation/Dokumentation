Das Geburtstagssystem ermöglicht Mitgliedern, ein Geburtsdatum zu hinterlegen und eine Geburtstagsbenachrichtigung auszuwählen. Eine optionale Rolle kann am Geburtstag vergeben werden.

## Modul einrichten und bearbeiten

Führe `/birthday-setup` aus. Discord öffnet eine **ephemere Nachricht**, die nur du sehen kannst. Wähle darin den Geburtstagskanal und optional die Geburtstagsrolle aus.

## Einstellungen & Parameter

| Befehl | Zweck |
| --- | --- |
| `/birthday-set` | Hinterlegt Tag und Monat sowie optional die gewünschte Geburtstagsbenachrichtigung. |
| `/birthday-edit` | Ändert ein bereits hinterlegtes Geburtsdatum oder die Benachrichtigung. |
| `/birthday-delete` | Löscht sämtliche gespeicherten Geburtstagsdaten. |
| `/birthday-greet-resend` | Sendet die Benachrichtigung zum aktuellen Geburtstag erneut in den Geburtstagskanal. |

Beim Hinterlegen erscheint eine Datenschutzabfrage. Das Geburtsdatum wird erst gespeichert, nachdem das Mitglied mit ✅ **Annehmen** zugestimmt hat.

## Wichtige Hinweise

- Informiere Mitglieder darüber, dass sie der Speicherung ausdrücklich zustimmen müssen.
- `/birthday-delete` löscht sämtliche Geburtstagsdaten des Mitglieds.
- Verwende für die optionale Geburtstagsrolle eine Rolle, die für den temporären Einsatz vorgesehen ist.
