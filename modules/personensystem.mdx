Das Personensystem ist ein Nutzerverzeichnis für Adminteams. Teammitglieder können eigene Einträge anlegen und Einträge einsehen. Eine Verwaltungsrolle darf Einträge bearbeiten und löschen. Optional kannst du Rechteanfragen einrichten.

## Einrichtung

Führe `/personen_setup` aus. Über die Buttons im Setup legst du Folgendes fest:

| Einstellung | Beschreibung |
| --- | --- |
| Team-Rolle | Darf Einträge einsehen und eigene Einträge hinzufügen. |
| Verwaltungsrolle | Darf Einträge einsehen, bearbeiten und löschen. |
| Hauptmenü-Kanal | Kanal für das Personenmenü. |
| Anfragen-Kanal | Kanal für Rechteanfragen. |
| Anfragen-Menü-Kanal | Kanal für das Menü, über das Rechte angefragt werden. |
| Log-Kanal (optional) | Protokolliert Rechteanfragen sowie neue, geänderte oder gelöschte Einträge. |
| Vordefinierte Rechte | Legt die verfügbaren Rechte-Gruppen für Rechteanfragen fest. |
| Anfragensystem | Schaltet das Rechteanfragensystem ein oder aus. |

<Note>
  Richte das Modul über `/personen_setup` in Discord ein. Im Dashboard kannst du eine vorhandene Konfiguration anpassen, aber kein Modul neu aktivieren.
</Note>

## Funktionen des Personenmenüs

- **Eintragen/Bearbeiten:** Bearbeite deinen eigenen Eintrag.
- **Mein Eintrag:** Zeige deinen gespeicherten Eintrag an.
- **Alle Einträge:** Sieh die verfügbaren Einträge ein.
- **Person suchen:** Suche im System nach passenden Nutzern.
- **Fehlende Einträge:** Ermittle, welche Mitglieder mit Team-Rolle noch keinen Eintrag haben.
- **Roblox-Spielerinformationen:** Frage Informationen zu einem gültigen Roblox-Nutzernamen über die API ab.
- **Verwaltung:** Wähle einen Nutzer aus und bearbeite oder lösche dessen Eintrag.
- **Nicht-Teameinträge löschen:** Lösche nach Bestätigung Einträge von Nutzern, die nicht mehr auf dem Server sind.

## Rechteanfragen

Wenn du das Anfragensystem aktivierst, kannst du vordefinierte Rechte-Gruppen für Anfragen bereitstellen. Lege dafür die Anfrage-Kanäle und die gewünschten Rechte im Setup fest.

## Hinweise

- Vergib die Verwaltungsrolle nur an Teammitglieder, die fremde Einträge bearbeiten oder löschen sollen.
- Die Anfragen-Kanäle und der Log-Kanal sind nur erforderlich, wenn du das Rechteanfragensystem beziehungsweise die Protokollierung verwenden möchtest.
- Prüfe die Auswahl, bevor du Einträge für Nicht-Teammitglieder löschen lässt.
