<Tip>
  Um schnell und einfach Hilfe zu bekommen, kannst du unserem [Discord-Server]({{discordInvite}}) beitreten!
</Tip>

## Vorraussetzungen

<Warning>
  **Wichtig:** Dein Server muss mindestens **10 Mitglieder** haben, damit der Bot dem Server beitritt und dort aktiv bleibt.
</Warning>

---

## Einrichtung Schritt für Schritt

<Steps>
  <Step title="Bot auf den Server einladen">
    Lade den Bot über den Einladungslink auf deinen Discord-Server ein.
  </Step>
  <Step title="Erforderliche Berechtigungen vergeben">
    Stelle sicher, dass der Bot folgende Berechtigungen auf deinem Server erhält:

    - **Server verwalten**
    - **Rollen verwalten**
    - **Kanäle verwalten**
    - **Administrator-Rechte** (empfohlen für eine reibungslose Funktion)
  </Step>
  <Step title="Broadcast-Kanal auswählen">
    Sobald der Bot dem Server beitritt, sendet er automatisch eine Nachricht mit einem **Drop-Down-Menü**:

    - Wähle dort den Kanal für **Broadcasts** aus (hierüber erhältst du wichtige Informationen und Updates).
    - Der Server-Eigentümer (Owner) erhält zusätzlich eine Bestätigung per **Direktnachricht (DM)**.
  </Step>
  <Step title="Befehle & Konfiguration nutzen">
    Nutze die Slash-Commands, um den Bot nach deinen Wünschen einzurichten:

    - Gib **`/all_commands`** ein, um eine Übersicht aller verfügbaren Befehle zu erhalten.
    - Richte anschließend die gewünschten Module und Funktionen Schritt für Schritt ein.
    - Der Bot sendet immer zur Konfiguration eines neuen Moduls eine Nachricht, wo die Rollen, Kanäle usw. ausgewählt und alles - was anpassbar ist - angepasst werden kann.
  </Step>
</Steps>
